# A Math Circle in Third Grade

**Evgeny Lakshtanov** (University of Aveiro, lakshtanov@ua.pt) &nbsp;·&nbsp; **Marek Tusiewicz** (marek@tusiewicz.eu)

Over the course of a school year, math circle sessions were run with an entire
third-grade class (~25 children, ages 9–10) at an ordinary Polish primary
school. This repository hosts the market-game spreadsheet template used in
class. The full article is on arXiv.

## Paper

📄 **arXiv:** [2609.39641](https://arxiv.org/abs/2609.39641)

## Market-game spreadsheet template

The trading game ("Ryneczek") is run from this spreadsheet — 50 rounds, a
facilitator-set apple price, and teams entering buy (+) / sell (−) decisions
each round:

📥 **In this repo:** [`ryneczek_template.xlsx`](ryneczek_template.xlsx) (tabs: `BASE`, `example game`)

Make a copy before using it with a class.
