# A Math Circle in Third Grade

**Evgeny Lakshtanov** (University of Aveiro, lakshtanov@ua.pt) &nbsp;·&nbsp; **Marek Tusiewicz** (marek@tusiewicz.eu)

Over the course of a school year, math circle sessions were run with an entire
third-grade class (~25 children, ages 9–10) at an ordinary Polish primary
school. The content was developed by a mathematician who speaks only basic
Polish; the sessions were led in Polish by a non-mathematician. That language
barrier shaped the whole format — minimal explanation, maximum action: many
games first, a short explanation only once the children start noticing the
pattern themselves.

This repository holds the article (English version) together with its figures
and the market-game spreadsheet template used in class.
